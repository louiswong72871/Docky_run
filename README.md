# 阿剛快跑

一個很輕的網頁奔跑動畫，玩法像瀏覽器的小恐龍：角色固定在左邊，世界由右往左走，看起來就是一直向右跑。

不必先做一支影片。按「開始播放」之後，阿剛會自己跳、自己蹲，畫面不停循環。想操作的話，按「自己挑戰」。

角色是原創大猩「阿剛」，不是任天堂的 Donkey Kong。畫面上的木桶、藤蔓、蜜蜂都是這個網頁自己畫的，沒有影片檔，也沒有外來圖片。

## 怎麼玩

- **開始播放**：自動循環。地上的木桶和木箱會跳過，頭上的藤蔓和蜜蜂會蹲低。
- **自己挑戰**：空白鍵、向上鍵、`W`，或點畫面、按「跳躍」來跳。向下鍵、`S`，或按住「蹲下」來蹲。
- **M**：開關聲音。最高分會留在這台瀏覽器裡。

開頭幾個障礙會標「跳」或「蹲」。

